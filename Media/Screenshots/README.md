# Ray Connection 3D Visual Pack

[English](README.en.md) | [Español](README.md)

Imágenes previstas para el proyecto **Ray Connection 3D**.

Este directorio está preparado para incluir los recursos visuales del proyecto en versiones originales y optimizadas para web.

- `rayconnection-thumbnail-01-ray-emitter.png`
- `rayconnection-thumbnail-02-mirror-placement.png`
- `rayconnection-thumbnail-03-board-rotation.png`
- `rayconnection-thumbnail-04-completed-connection.png`

## Uso recomendado

- `rayconnection-logo.webp` para identidad del proyecto.
- `rayconnection-cover.webp` para Open Graph, portada y redes.
- `rayconnection-banner.webp` para la web portfolio.
- Las miniaturas para cards, documentación, README o previews técnicas.
