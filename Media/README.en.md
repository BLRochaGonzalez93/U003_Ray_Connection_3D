# Ray Connection 3D Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **Ray Connection 3D** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

## Planned contents

### original-png/

PNG versions separated from the mockup or original artwork.

- `rayconnection-logo.png`
- `rayconnection-cover.png`
- `rayconnection-banner.png`
- `rayconnection-thumbnail-01-ray-emitter.png`
- `rayconnection-thumbnail-02-mirror-placement.png`
- `rayconnection-thumbnail-03-board-rotation.png`
- `rayconnection-thumbnail-04-completed-connection.png`

### webp/

The same images converted to `.webp` for web usage.

- `rayconnection-logo.webp`
- `rayconnection-cover.webp`
- `rayconnection-banner.webp`
- `rayconnection-thumbnail-01-ray-emitter.webp`
- `rayconnection-thumbnail-02-mirror-placement.webp`
- `rayconnection-thumbnail-03-board-rotation.webp`
- `rayconnection-thumbnail-04-completed-connection.webp`

### _source/

Original complete composite image, in PNG and WEBP.

- `rayconnection-generated-composite.png`
- `rayconnection-generated-composite.webp`

## Recommended usage

- `rayconnection-logo.webp` for project identity.
- `rayconnection-cover.webp` for Open Graph, cover and social sharing.
- `rayconnection-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.
